# APIL — /brag Launch Video Plan

**Project:** APIL (Agent Payment Integrity Layer)  
**Format:** 1920×1080 Landscape, 30fps  
**Target Duration:** 20.0 seconds (600 frames)  
**Tone:** `cinematic` / `polished` (High-contrast fintech cyberpunk security)  

---

## 1. Concept & Positioning
- **Angle:** You wouldn't let an intern wire company money with no approval chain. Why let an autonomous LLM agent talk directly to a payment gateway?
- **Hook (0:00 - 3.5s):** An AI agent shopping for hardware encounters dark-pattern checkout price drift (+₹400 hidden fee).
- **The Core Reveal (3.5s - 7.5s):** APIL Pre-Execution Invariant Gate blocks the transaction in <2ms before PayPal API is ever contacted.
- **Swarm Governance (7.5s - 12.0s):** Multi-agent swarm budget tree (Hardware, Travel, Supplies personas) with non-fungible real-time quota meters.
- **Verification & Post-Payment (12.0s - 16.5s):** Live PayPal Sandbox authorization, HMAC-SHA256 signed audit receipt export, and async dispute/refund webhook simulation.
- **Punchline & Proof (16.5s - 20.0s):** Empirical benchmark matrix: Direct LLM 14.3% vs APIL 100% pass rate. "Zero Drift. Zero Escapes."
